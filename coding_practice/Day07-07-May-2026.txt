Install NGINX on Amazon Linux EC2 and Host a Simple Website

Step 1: Launch EC2 Instance

Create an EC2 instance using:

AMI: Amazon Linux
Instance Type: t2.micro (Free Tier)
Security Group:
Allow SSH (22)
Allow HTTP (80)

Step 2: Connect to EC2

ssh -i your-key.pem ec2-user@YOUR_PUBLIC_IP

Step 3: Update Server

sudo yum update -y
sudo dnf update -ycd /usr/share/nginx/html

Step 4: Install NGINX

sudo dnf install nginx -y

Step 5: Start NGINX Service

sudo systemctl start nginx

Enable NGINX on boot:
sudo systemctl enable nginx

Check status:
sudo systemctl status nginx

Step 6: Verify NGINX

Open browser >> http://YOUR_PUBLIC_IP >> You should see: >> Welcome to nginx

Step 7: Create Simple Website

Move to nginx html directory:

cd /usr/share/nginx/html

sudo rm -f index.html

Step 8: Create Your Website

Create a new simple html 

sudo vi index.html

press i to insert
------------------------------
<!DOCTYPE html>
<html>
<head>
    <title>My First Website</title>
    <style>
        body {
            background-color: #1e293b;
            color: white;
            text-align: center;
            font-family: Arial;
            margin-top: 100px;
        }

        h1 {
            color: #38bdf8;
        }
    </style>
</head>
<body>

    <h1>Hello from EC2 + NGINX!</h1>
    <p>Website hosted on Amazon Linux EC2 instance.</p>

</body>
</html>
----------------------------
press ESC to exit insert mode and :wq to save and exit

Step 9: Restart NGINX

sudo systemctl restart nginx

Step 10: Access Website

http://YOUR_PUBLIC_IP

If you port 80 is not enabled then go to security group of your ec2 and enable http >> port 80 >> from your IP in Inbound rules.
