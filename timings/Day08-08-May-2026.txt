# 📦 AWS Batch

## What is AWS Batch?

Service to run batch computing jobs at scale.

## Features

* Automatically provisions compute resources
* Supports Docker containers
* Handles job queues and scheduling

## Compute Options

* EC2
* Spot Instances
* Fargate

## Use Cases

* Data processing
* Image/video rendering
* Scientific workloads

## Interview Points

* Used for large-scale background jobs
* Cost optimization with Spot instances
* Integrates with ECS/EKS

# 📁 Amazon Elastic File System (EFS)

## What is EFS?

Managed scalable shared file storage for Linux workloads.

## Features

* Shared across multiple EC2 instances
* Automatically scales
* Highly available

## Access

* Mounted via NFS protocol

## Use Cases

* Shared application storage
* Kubernetes persistent storage
* CMS systems

## Interview Points

* Regional service
* Supports concurrent access
* More expensive than EBS but shared

# 🚚 AWS Snowball

## What is Snowball?

Physical device for transferring large amounts of data into/out of AWS.

## Use Cases

* Data center migration
* Backup transfer
* Limited network bandwidth scenarios

## Types

* Snowball Edge Storage Optimized
* Snowball Edge Compute Optimized

## Interview Points

* Offline data transfer solution
* More secure and faster for PB-scale data migration
* Data encrypted using KMS
