
# 1. What is Helm?

Helm is the package manager for Kubernetes.

Similar to:

* apt → Ubuntu
* yum → RHEL
* npm → NodeJS

Helm helps:

* Install applications
* Upgrade applications
* Rollback applications
* Template Kubernetes YAMLs

---

# 2. Why Helm is Needed

Without Helm:

* Huge YAML files
* Repetitive configs
* Difficult upgrades
* Manual deployments

Helm solves:

* Reusability
* Versioning
* Templating
* Easy deployments

---

# 3. Helm Architecture

Main Concepts:

* Chart
* Repository
* Release
* Values.yaml
* Templates

---

# 4. Important Helm Terminologies

| Term        | Meaning                  |
| ----------- | ------------------------ |
| Chart       | Helm package             |
| Repository  | Collection of charts     |
| Release     | Installed chart instance |
| Values.yaml | Configuration file       |
| Template    | Dynamic Kubernetes YAML  |

---

# 5. Helm Workflow

Helm Chart → Render Templates → Kubernetes Resourcesa

1. Helm reads templates
2. Replaces variables from values.yaml
3. Generates final YAML
4. Deploys to Kubernetes

---

# 6. Helm Chart Structure

mychart/
├── Chart.yaml
├── values.yaml
├── charts/
├── templates/
---

# 7. Important Helm Files

## Chart.yaml

Contains chart metadata.

Example:

apiVersion: v2
name: nginx-chart
version: 1.0.0

---

## values.yaml

Stores configurable values.

Example:

replicaCount: 2

image:
  repository: nginx


---

## templates/

Contains Kubernetes YAML templates.

Example:

replicas: {{ .Values.replicaCount }}

---

# 9. Important Helm Commands

# Repository Commands

## Add Repo

helm repo add bitnami https://charts.bitnami.com/bitnami

---

## Update Repo

helm repo update

---

## Search Charts

helm search repo nginx

---

# Release Commands

## Install Chart

helm install my-nginx bitnami/nginx

---

## List Releases

helm list

---

## Upgrade Release

helm upgrade my-nginx bitnami/nginx

---

## Rollback Release

helm rollback my-nginx 1

---

## Uninstall Release

helm uninstall my-nginx

---

# Debugging Commands

## Dry Run

helm install my-nginx bitnami/nginx --dry-run

---

## Template Rendering

helm template my-nginx bitnami/nginx

---

## Get Values

helm get values my-nginx

---

## History

helm history my-nginx

# 13. Helm vs kubectl

| Helm                  | kubectl         |
| --------------------- | --------------- |
| Package manager       | CLI tool        |
| Templates YAML        | Applies YAML    |
| Supports rollback     | Manual rollback |
| Versioned deployments | No versioning   |

# 27. EKS Provisioning Commands

# Create EKS Cluster (eksctl)

--name demo-cluster \
--region ap-south-1 \
--nodegroup-name workers \
--node-type t3.medium \
--nodes 2


---

## Get Cluster

eksctl get cluster


---

## Delete Cluster

eksctl delete cluster --name demo-cluster


---

# Update kubeconfig

aws eks update-kubeconfig \
--region ap-south-1 \
--name demo-cluster

---

# Verify Cluster
