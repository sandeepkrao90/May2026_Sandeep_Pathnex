Today I Dockerize NGINX Website on Amazon Linux EC2

Browser
   ↓
EC2 Instance
   ↓
Docker Container
   ↓
NGINX
   ↓
HTML Website

Step 1: Connect to EC2

ssh -i your-key.pem ec2-user@YOUR_PUBLIC_IP

Step 2: Install Docker

sudo dnf install docker -y

Step 3: Start Docker

sudo systemctl start docker

Enable at boot:

sudo systemctl enable docker

Check status:

sudo systemctl status docker

Step 4: Give Docker Permission to ec2-user

sudo usermod -aG docker ec2-user

Apply group changes:

newgrp docker

Verify

docker ps

Step 5: Create Project Directory

mkdir nginx-docker-app

cd nginx-docker-app

Step 6: Create index.html

vi index.html

Press i to Insert Modes

----------------------

<!DOCTYPE html>
<html>
<head>
    <title>Docker NGINX Website</title>
    <style>
        body {
            background-color: black;
            color: white;
            text-align: center;
            margin-top: 100px;
            font-family: Arial;
        }

        h1 {
            color: cyan;
        }
    </style>
</head>
<body>

<h1>Hello from Docker + NGINX!</h1>
<p>Website running inside Docker container on EC2.</p>

</body>
</html>

----------------------------

ESC :wq

Step 7: Create Dockerfile

vi Dockerfile

FROM nginx:latest

COPY index.html /usr/share/nginx/html/index.html

ESC :wq

Step 8: Build Docker Image

docker build -t my-nginx-app .

Verify Image 

Step 8: Build Docker Image

my-nginx-app

Step 9: Run Docker Container

docker run -d -p 80:80 --name nginx-container my-nginx-app

http://YOUR_PUBLIC_IP
