# ⚡ Lambda

## What is Lambda?

Serverless compute service to run code without managing servers.

## Key Features

* Event-driven
* Auto scaling
* Pay per execution
* Supports multiple languages

## Common Triggers

* S3
* API Gateway
* CloudWatch Events/EventBridge
* DynamoDB Streams

## Important Concepts

* Execution Role
* Timeout
* Memory Allocation
* Cold Start

## Interview Points

* Max execution timeout → 15 mins
* Stateless service
* Good for automation/microservices
* Concurrency controls scaling

# 🛡️ AWS Shield

## What is AWS Shield?

Protection against DDoS attacks.

## Types

* Shield Standard (free)
* Shield Advanced (paid)

## Protects

* CloudFront
* Route 53
* ELB
* Global Accelerator

## Interview Points

* Layer 3 & Layer 4 DDoS protection
* Shield Standard enabled by default
* Advanced provides detailed attack visibility

---

# 🔥 AWS WAF (Web Application Firewall)

## What is WAF?

Protects web applications from common web exploits.

## Protects Against

* SQL Injection
* Cross-Site Scripting (XSS)
* Bad Bots
* IP blocking

## Works With

* CloudFront
* ALB
* API Gateway

## Features

* Rate limiting
* Custom rules
* Managed rule groups

## Interview Points

* Operates at Layer 7 (HTTP/HTTPS)
* Used together with Shield for better protection

# 🔐 AWS Key Management Service (KMS)

Managed encryption key service.

* Envelope Encryption

## Integrations

* S3
* EBS

* Lambda

## Features

# ⚡ Amazon Aurora

## What is Aurora?

AWS-managed high-performance relational database compatible with MySQL/PostgreSQL.

## Benefits

* Faster than standard MySQL/Postgres
* Auto scaling storage
* Highly available

## Architecture

* 6 copies across 3 AZs

## Features

* Aurora Serverless
* Read Replicas
* Fast failover

## Interview Points

* Better performance than RDS MySQL
* Storage auto grows
* Shared distributed storage architecture

Fully managed data warehouse service.

# 🔄 AWS DMS (Database Migration Service)

## What is DMS?

Service to migrate databases to AWS with minimal downtime.

## Supports

* Homogeneous migration

  * MySQL → MySQL
* Heterogeneous migration

  * Oracle → PostgreSQL

## Features

* Continuous replication
* CDC (Change Data Capture)
* Minimal downtime

## Components

* Replication Instance
* Source Endpoint
* Target Endpoint

## Interview Points

* Used during cloud migration
* Supports ongoing replication
* Schema conversion may need SCT tool

# 🔥 Important Interview Comparisons

## RDS vs DynamoDB

* RDS → Relational SQL DB
* DynamoDB → NoSQL key-value DB

## Aurora vs RDS

* Aurora faster and cloud optimized
* Better HA and storage scaling

## Shield vs WAF

* Shield → DDoS protection
* WAF → HTTP attack protection

## GuardDuty vs Inspector

* GuardDuty → Threat detection/monitoring
* Inspector → Vulnerability scanning

## Redshift vs RDS

* Redshift → Analytics/Data warehouse
* RDS → Transactional database
